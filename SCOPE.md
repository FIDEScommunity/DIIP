# Scope

The scope if this repository is the Decentralized Identity Interoperability Profile (DIIP)
and its various versions.

The *Specification License* in the [LICENSE](LICENSE) file covers the DIIP specification
and the various previews related to pull requests tp the `development` branch (files in the
[spec](spec) folder and the corresponding HTML files.)

This repository uses the [Spec-Up](https://github.com/decentralized-identity/spec-up)
system and [GitHub Actions](https://github.com/features/actions) for rendering the
specification from Markdown to HTML. The files related to the building and publishing the
specification are licensed under the *Source Code License* in the [LICENSE](LICENSE) file.

Any changes of Scope are not retroactive.
